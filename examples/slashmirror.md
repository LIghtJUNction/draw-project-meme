# 示例：SlashMirror（仅凭源码、单功能）

这是虚构教学项目，专门演示“实际只有一个功能时不凑功能数量”。

## 用户输入

````text
用 $draw-project-meme 根据以下源码绘制荒诞梗图，不联网：

项目名：SlashMirror

```python
import sys
print(sys.argv[1].replace('/', chr(92)))
```

让画面像一座夸张的转换塔，但不要编造文件处理、网络传输、跨平台同步等功能。
````

## 应选择的笑点

**事实：**输入一个命令行字符串，替换字符串中的 `/` 为 `\`，再输出。这就是全部功能。

**画法：**一台高得离谱、用铁皮胡乱拼装的转换塔，一条印着 `a/b/c` 的纸带穿过塔中央一个小小的字符替换夹头，出来时变成 `a\b\c`。夸张机器体积，保留输入 → 替换 → 输出的单一因果关系。

**允许的标签：**`SlashMirror`、`输入`、`str.replace`、`输出`。如果模型不能稳定绘制反斜杠，可以省略纸带上的具体字符。

不要为了把塔画得很满，给这个只有一行核心操作的项目虚构四五个独立模块。
